1. Equinox Local’i kurun

Bilgisayarınıza uygun kurulumu seçin. İki kurulum da kullanıcı seviyesinde çalışır, x64 veya ARM64 mimarisini algılar, sabitlenmiş sürüm boyutunu ve SHA-256 değerini doğrular ve ayrı Node kurulumu gerektirmeden çalışma ortamını kurar.

macOS

TERMINALApple Silicon + Intel

Normal macOS kullanıcınızla, sudo kullanmadan çalıştırın. Önce shell kurulum betiğini inceleyebilirsiniz.

macOS kullanıcı Library klasörüne kurar ve Equinox Local.app uygulamasını açar. Windows kullanıcıya özel LocalAppData altına kurar, yerel uygulamayı ve Chrome Native Messaging kaydını hazırlar ve Equinox Local penceresini açar.

2. Agent Access’i inceleyin

Kurulum, yerel Equinox Local uygulamasını açar. Penceredeki Control Center, bilgisayarınızdaki özel loopback hizmetine bağlıdır. http://127.0.0.1:24891/ adresi de tanılama amaçlı alternatif olarak kullanılabilir.

  1. Çalışma durumunu kontrol edin. Yapay zekâ istemcinizi bağlamadan önce bildirilen kurulum sorunlarını giderin.
  2. Agent Access’i gözden geçirin. Yeni yönetilen kurulumlar Full modunda başlar. Kök farkındalığı olan yapılandırılmış yetenekleri belirlediğiniz projeler ve klasörlerle sınırlamak için Selected modunu seçin.
  3. Çalıştırma ve otomasyonu ayrı değerlendirin. Terminal/süreç ve Browser kontrolleri iki platformda da bulunur. Desktop otomasyonu şu anda yalnızca macOS’tadır. Çekirdek çalışma ortamı isteğe bağlı entegrasyonları gerektirmez.

Selected kökler Terminal için sandbox değildir. Terminal, oturum açtığınız işletim sistemi kullanıcısının yetkileriyle çalışır ve başladıktan sonra Selected köklerle sınırlı kalmaz. Kesin klasör sınırlaması gerekiyorsa Terminal’i kapatın. Equinox tarafından yönetilen sağlayıcı kimlik bilgileri genel Terminal/süreç ortamlarına aktarılmaz.

3. ChatGPT’yi bağlayın

Equinox Local bilgisayarınızda çalışır; ChatGPT, OpenAI Secure MCP Tunnel üzerinden bağlanır. Tünel dışarıya giden bir HTTPS bağlantısı kurar; gelen bağlantılar için güvenlik duvarı kuralı veya herkese açık yerel port gerekmez.

Önce OpenAI planınızın ve ChatGPT çalışma alanınızın kullanmak istediğiniz özel MCP uygulaması/bağlayıcısı akışını desteklediğini doğrulayın. Erişim ve yazma/değiştirme izinleri OpenAI tarafından belirlenir ve Local’den bağımsız değişebilir.

  1. OpenAI Platform → Tunnels bölümünde Local’i kullanacak ChatGPT çalışma alanına bağlı bir tünel oluşturun. Tunnel ID değerini kopyalayın.
  2. OpenAI Platform → API keys bölümünde yalnızca Tunnels: Read + Use izinlerine sahip Restricted runtime API anahtarı oluşturun. Tunnel ID ve runtime anahtarı iki farklı değerdir. Uzun süre çalışan runtime için admin anahtarı kullanmayın.
  3. Control Center → Connect to ChatGPT bölümüne iki değeri de girin ve Save & connect seçeneğini kullanın. Local anahtarı özel yerel durumda saklar ve tünel moduna geçmek için kontrollü yeniden başlatma planlar.
  4. ChatGPT web’de özel MCP uygulaması/bağlayıcısı kurulumunda Connection: Tunnel seçin ve aynı Tunnel ID’yi seçin veya yapıştırın.
  5. Bağlantı kurulduğunda ChatGPT’de uygulamanın araçlarını tarayın veya yenileyin.

Tünel görünmüyorsa çalışma alanı kapsamını, ilgili hesabın Read + Use izinlerini ve iki tarafın aynı ID’yi kullandığını kontrol edin. Yeni tünellerin görünmesi kısa bir süre alabilir. Ayrıntılar açık kaynak depodaki tünel rehberinde.

4. Equinox Browser’ı ekleyin

Bu adım isteğe bağlıdır. Equinox Browser hem ayrı Agent Browser hem de kişisel Your Browser için tarayıcı otomasyonu sağlar.

  1. Control Center → Browser bölümünden Agent Browser’ı açın veya hazırlayın. Bu, ayrı Equinox Local Chrome profiliyle varsayılan bağlamdır.
  2. Bu profile Chrome Web Store’dan Equinox Browser’ı kurun.
  3. Eklentiyi açın, tarayıcı verisi açıklamasını okuyup kabul edin, ardından tarayıcı kontrolünü açıkça etkinleştirin. Yeni eklenti kurulumları otomasyon kapalı olarak başlar.
  4. İşlerin mevcut kişisel oturumlarınızı da kullanmasını istiyorsanız eklentiyi kişisel Chrome profilinize ayrıca kurup etkinleştirin. Bu işler için Your Browser açıkça seçilmelidir.

Bağlamların onay ve gezinme durumları birbirinden bağımsızdır. Local birinden diğerine sessizce geçmez. Eklenti güncellemelerini Local güncelleyicisi değil, Chrome Web Store yönetir.

5. İsteğe bağlı entegrasyonlar

macOS’ta masaüstü kontrolü

Desktop otomasyonu şu anda yalnızca macOS’tadır. macOS’ta Ekran Kaydı ve Erişilebilirlik izinlerini ürünün sabit kimliği olan Equinox Local.app uygulamasına verin. Windows Local v1 Desktop otomasyonu sunmaz.

Telegram teslimatı

Control Center → Integrations bölümüne bot token’ınızı ve Your Telegram ID değerinizi girip Connect & test seçin. Botun size mesaj gönderebilmesi için önce onunla özel sohbet başlatın. Alıcı, grup veya kanal değil, tek bir özel Telegram kullanıcısı olmalıdır.

Ajanlar bu sabit alıcıya mesaj metni gönderebilir. Alıcıyı değiştiremez veya Telegram gelen kutusunu okuyamazlar. Token ve alıcı özel yerel depoda tutulur, ajanlara döndürülmez.

Güncelleme ve kaldırma

Kararlı Local güncellemelerini Control Center’dan yönetin. Güncelleyici Ed25519 imzalı meta veriyi ve indirilen paketi doğrular, sürümlü kurulumu hazırlar, etkinleştirme sonrası sağlığı kontrol eder ve başarısızlık durumunda önceki sürümü geri yükler.

Normal kaldırma işlemi yerel çalışma alanını ve yapılandırmayı korur. Tüm yerel verileri silmek, yazılı onay gerektiren ayrı bir seçimdir. Equinox Browser, Chrome’dan ayrıca kaldırılır.

Yardım gerekiyor mu?

Kurulum hatalarında ilgili Terminal veya PowerShell mesajını saklayın. Sağlıksız çalışma durumunda Control Center tanılamalarını inceleyin. İletişim üzerinden en küçük yararlı açıklamayı gönderin; paylaştığınız günlüklerde kimlik bilgileri ve ilgisiz özel veriler bulunmasın.
