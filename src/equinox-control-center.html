Safe boundary

No silent browser fallback

Agent Browser and Your Browser are separate contexts on the same Equinox Browser bridge. If Agent Browser is unavailable, Equinox Local fails closed instead of silently using your personal Chrome. Direct user-Chrome CDP fallback remains disabled.
